## 🎯 FLUXO RECOMENDADO

### Novo Desenvolvedor
```
1. Ler README.md (visão geral)
   ↓
2. Executar QUICK_START.sh/bat
   ↓
3. Testar pnpm web (dev server)
   ↓
4. Ler .github/copilot-instructions.md
   ↓
5. Começar desenvolvimento
```

### Para Deploy em Produção
```
1. Ler SETUP_FINAL.md (entender processo)
   ↓
2. Seguir GITHUB_SECRETS_SETUP.md (adicionar credenciais)
   ↓
3. Verificar PRODUCTION_CHECKLIST.md (validação)
   ↓
4. Fazer git push para main
   ↓
5. Acompanhar GITHUB_SECRETS_SETUP.md#verificação
```

### Para Publicar na Play Store
```
1. Ter acesso ao PLAY_STORE_CHECKLIST.md
   ↓
2. Ter acesso ao GITHUB_SECRETS_SETUP.md (especialmente Play Store JSON)
   ↓
3. Seguir passos em ordem
   ↓
4. Validar em PRODUCTION_CHECKLIST.md
```
