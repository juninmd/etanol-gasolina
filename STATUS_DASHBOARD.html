🎯 Lógica Comercial

Regra de Ouro:

SE preço_etanol ≤ (preço_gasolina × 0.70)
✓ Etanol é mais econômico
✗ Gasolina é mais econômico

Padrão brasileiro: etanol só compensa se custar até 70% do preço da gasolina.

🚀 Próximos Passos para Deploy

1

Criar Conta Expo (Uma vez)

Acesse https://expo.dev e crie uma conta gratuita

npm install -g eas-cli
eas auth login
2

Gerar EXPO_TOKEN

Crie um token para CI/CD

eas token create --non-interactive

Copie o token gerado

3

Configurar GitHub Secrets

Vá para: Settings → Secrets → Actions

Adicione:

  • EXPO_TOKEN - Token do passo anterior
  • PLAY_STORE_SERVICE_ACCOUNT_JSON - Credenciais Google Play
4

Setup Google Play Console

Crie aplicação com:

  • Nome: Etanol ou Gasolina
  • Package: com.etanol.gasolina
  • Categoria: Ferramentas
  • Service Account Key: JSON do Cloud Console
5

Deploy em Produção

Faça um commit e push para main:

git add .
git commit -m "Release v1.0.0"
git push origin main

✓ GitHub Actions será acionado automaticamente

Acompanhe em: Actions → Build and Deploy to Play Store

💻 Testando Localmente

⚠️ Importante: Instale as dependências primeiro com pnpm install

Web Preview (Recomendado para testes)

pnpm web

→ Abre em http://localhost:8081

Android (Dispositivo ou Emulador)

pnpm android

Preview Build (APK para teste)

eas build --platform android --profile preview --wait

→ Gera APK instalável em dispositivos

Testes Automatizados

pnpm test
